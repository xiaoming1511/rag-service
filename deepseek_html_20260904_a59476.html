🧠 RAG 知识库系统 — 完整技术方案总结

基于 oMLX + ChromaDB + FastAPI + Obsidian 的本地知识库搭建方案

📌 一、系统概述

本系统是一个完全本地运行的 RAG（检索增强生成）知识库，基于 oMLX 提供 LLM 推理， ChromaDB 提供向量存储，FastAPI 提供 API 服务， Obsidian 提供知识管理界面。

组件 选型 作用 状态
LLM 推理 oMLX 0.6.4 本地运行 LLM，支持 OpenAI 兼容 API ✅ 已部署
聊天模型 gemma-4-e4b-it-mxfp4 生成回答 ✅ 已加载
嵌入模型 bge-m3-mlx-4bit 文本向量化（1024 维） ✅ 已加载
重排序模型 bge-reranker-v2-m3 检索结果精排 ✅ 已加载
向量数据库 ChromaDB（嵌入式） 存储向量和元数据 ✅ 已部署
API 服务 FastAPI + Uvicorn 提供 RESTful API ✅ 已部署
知识管理 Obsidian + Custom Frames 前端界面 + 笔记管理 ✅ 已集成

🌐 四、API 接口

服务地址: http://127.0.0.1:8080

接口 方法 说明
/v1/health GET 健康检查
/v1/status GET 系统状态
/v1/index POST 建立/重建索引
/v1/query POST 非流式问答
/v1/query/stream POST 流式问答（SSE）

📌 调用示例

# 1. 健康检查
curl http://127.0.0.1:8080/v1/health

# 2. 建立索引
curl -X POST http://127.0.0.1:8080/v1/index \
  -H "Content-Type: application/json" \
  -d '{"source_dirs": ["/Users/xuhuaming/projects/obsidian"], "rebuild": true}'

# 3. 流式问答
curl -X POST http://127.0.0.1:8080/v1/query/stream \
  -H "Content-Type: application/json" \
  -d '{"question": "Redis 支持哪些数据结构？", "top_k": 3}'

# 4. 非流式问答
curl -X POST http://127.0.0.1:8080/v1/query \
  -H "Content-Type: application/json" \
  -d '{"question": "Python 有哪些数据类型？", "top_k": 3}'

✅ 五、关键技术决策

决策项 最终选择 理由
分块策略 按 Markdown 标题切分 保持语义完整性，保留来源结构
同步/异步 同步流式 Python 3.13 + httpx 异步存在兼容性问题
重排序 默认启用，可配置开关 提升检索精度，可灵活控制
流式输出 支持 提升用户体验
开发顺序 CLI 验证 → API 封装 先验证功能，再封装服务
索引策略 先全量，后续增量 简化初期实现
配置文件 YAML 可读性好，便于维护
向量数据库 ChromaDB（嵌入式） 轻量级，无需独立服务

🔗 七、Obsidian 集成

1. Custom Frames 配置

  • 插件: Custom Frames
  • URL: http://127.0.0.1:8080
  • Display Name: RAG AI
  • 启用条件: API 服务必须运行

2. 来源链接问题说明

现状：来源显示为可点击的链接（蓝色下划线），点击后会尝试通过 obsidian:// 协议打开对应笔记。

前提条件：

  • Obsidian 必须已经打开（支持 obsidian:// URL Scheme）
  • Vault 名称必须与 VAULT_NAME 配置一致
  • 文件路径必须相对于 Vault 根目录

当前障碍：Obsidian 的 URL Scheme 在 WebView（Custom Frames）中可能被拦截， 导致无法跳转。这是 Obsidian 的安全限制，可以通过以下方式解决：

  • 在系统浏览器中打开 obsidian:// 链接
  • 或开发一个 Obsidian 插件直接调用 app.vault API

🐛 九、遇到的问题与解决方案

问题 原因 解决方案
异步流式报错 Python 3.13 + httpx 兼容性问题 改用同步流式 (generate_stream_sync)
测试连接失败 LLM Wiki 插件 BUG 切换到统一模型模式
API Key 错误 oMLX 跳过认证但 Copilot 要求填写 填入任意占位符 dummy
配置文件找不到 PyCharm 工作目录不是项目根目录 修改 config.py 使用 __file__
来源链接无法点击 Obsidian WebView 拦截 obsidian:// 开发 Obsidian 插件 或 使用系统浏览器
检索结果少 similarity_threshold 过滤 降低阈值到 0.1 或 0.05
