一、系统定位（请以此为准）

本系统的定位：不是替代 Obsidian，也不是替代 LLM Wiki，而是充当三者中的"能力层/使用层"：

📒 Obsidian 负责"存"

笔记、双链、图谱的载体，是你的知识库本体，本系统只读它、不改造它（除你主动开启的沉淀/知识层写入）。

🧩 LLM Wiki 负责"理"（可选并行）

把素材自动整理成结构化 wiki 页面（你 vault 里已有的 xu/wiki 结构）。满足需求时优先用它的产物。

⚙️ 本系统负责"用"

检索-问答-沉淀-自动化-对外接口。它是一层可编程（REST/CLI）、可集成（Obsidian 原生插件/Web）、可扩展（解析器/向量库/配置抽象）的服务。

🎯 触发条件

当 LLM Wiki 无法满足你的个人需求（程序化调用、自定义管道、精确引用跳转、队列/研究/沉淀等）时，由本系统补齐。

一句话：知识归 Obsidian 管，知识层归 LLM Wiki 管（可选），知识"使用"归本系统管。三个工具并行互不干扰。

二、当前功能全景

2.1 核心问答链路 ✅

  • 向量检索 + 重排序：bge-m3 嵌入（1024 维）初检 → bge-reranker 精排 → 相似度阈值过滤（0.5）
  • 严格来源模式：检索为空时不调用模型，诚实告知"未找到"（retrieval.strict_sources，默认关）
  • 相同问题响应缓存：命中直接从 6s+ 降到 2ms（可配置 TTL/开关）
  • 同步 / 异步 / 流式（SSE）三通道；异步基于 AsyncOpenAI，规避 Python 3.13 的 httpx 流关闭问题
  • 多轮对话：历史裁剪（最近 10 轮 + 2000 token 预算）、可选 LLM 追问改写（默认关）、前端回传历史

2.2 索引与多格式 ✅

  • 增量索引：manifest 三态同步（新增/变更先删后加/删除），两段式检测（mtime+size → 内容 MD5），免全量重建
  • watchdog 自动监听：服务内置监听源目录，文件变化去抖后自动增量
  • 后台摄入队列：单 worker 串行 + 磁盘持久化（崩溃恢复）、进度查询与取消（/v1/index/async、/v1/index/jobs）
  • 7 种格式 + URL：Markdown、TXT、PDF(PyMuPDF)、Word(python-docx)、HTML(bs4)、EPUB(ebooklib)、PPTX(python-pptx)、远程网页（/v1/index/url）

2.3 知识使用与增值功能 ✅

  • 问答沉淀 syntheses：每次问答写为 vault 根 syntheses/ 的 .md（含 frontmatter+来源），会被再次检索 → 知识记忆循环
  • Deep Research 简版：问题 → LLM 拆 3-5 子查询 → 并行检索合并 → 带引用汇总报告（/v1/research）
  • AI 知识层生成 wiki-builder：为每篇文档生成来源摘要页 + 自动建/更新概念页、实体页，[[互链]]，维护 index.md/log.md（写入既有 xu/wiki/；增量同步后自动串联，可关）
  • 周期维护：定时补齐知识层（wiki.maintain_interval_min，默认关）

2.4 对外界面与工具 ✅

  • Obsidian 原生插件（TypeScript）：侧边栏聊天（SSE 流式+多轮）、引用点击跳转打开笔记（含标题锚点定位）、状态栏、设置面板、命令面板、自动索引（保存防抖+定时兜底）
  • Web 聊天页：浏览器流式聊天 + "🕸 图谱"按钮（见冗余标识）
  • CLI：index / query / stats / watch
  • REST API：/v1/query、/v1/query/stream、/v1/index、/v1/index/refresh、/v1/index/url、/v1/index/async、/v1/index/jobs、/v1/research、/v1/wiki/build、/v1/graph、/v1/health、/v1/status
  • 质量保障：91 项自动化测试、Git 版本管理、中文注释、设计文档（docs/optimization-plan.md）

七、使用入口

  • 启动服务：python run_api.py（默认 http://127.0.0.1:8080，文档 /docs）
  • 命令行：python cli/main.py {index|query|stats|watch}
  • Obsidian 插件：已安装至 ~/projects/obsidian/.obsidian/plugins/rag-service/，启用后命令面板 "打开 RAG 聊天面板"
  • Web：浏览器打开 http://127.0.0.1:8080
  • 配置：config/settings.yaml（模型/阈值/严格模式/沉淀/性能/wiki）
